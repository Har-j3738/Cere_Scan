# Security Policy

## Scope

CereScan is an educational/research repository. Security reports about the application, dependency configuration, CI workflow, or accidentally committed credentials are welcome.

## Reporting

Please report suspected vulnerabilities privately through GitHub's repository security reporting features when available. Do not disclose secrets, credentials, or exploitable details in a public issue.

## Supported versions

Only the current `main` branch is actively maintained.

## Important

Do not upload real patient-identifying medical images, credentials, API keys, or other sensitive information to this repository or its issue tracker.
